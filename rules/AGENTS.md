# Game Localization & Culturalization Rules

Whenever the user asks to translate, localize, culturalize, audit, or polish video game text, string tables, UI labels, tutorials, lore, or dialogue in any language.

1. **Activate `game-cultural-localization` first.** Read the skill's `SKILL.md`, then load **only** `references/<locale>.md` for the active target locale (plus `references/methodology_and_qa.md` and `references/transcreation_ledger_guide.md` when running a full-table pipeline). Never load other locales' playbooks.
2. **Context map before any word.** The first step of every run is the context map of the game, nothing is translated or judged before it exists. `context-cartographer` (Claude Opus, role `context_orchestrator`) studies the code, scenes, prefabs, data assets, string tables and lore with `context-scout` agents (Claude Sonnet, role `context_agent`), asks the user whenever a usage, meaning, tone or audience stays unclear, and writes `CONTEXT_MAP.md`. Every translator, critic and juror reads the map first. Language is flexible, one source word takes different target words depending on where it is used (*Play* is *Oyna* for a game and *Çal* for music), so meaning comes from the map, never from a locked term list.
3. **Culturalize for the ear, never word-for-word.** Literal, grammatically correct translation (*translationese / Übersetzungsdeutsch / français traduit / 번역투 / 翻訳調 / 翻译腔 / канцелярит / çeviri kokusu*) is a defect. Every line must sound like a native speaker or gamer says it in everyday life, calibrated to the A1 to A5 voice archetypes.
4. **Four phases, never fewer.** Phase 0 (context map first, then checksums, concatenation scan, fonts, `<LOCALE>_BIBLE.md`, ledger) → Phase 1 clean-room Pass 1 (`game-culturalizer`) → Phase 2 blind critique + Pass 2 → Phase 3 automated gate. Never deliver a raw Pass 1 as finished work.
5. **Blind slice is mandatory.** The critic (`native-ear-critic`) only ever receives a file produced by `skills/game-cultural-localization/scripts/make_blind_slice.py` (key + context + target text, **no source column**) together with the context map. It returns `critique_<locale>_<batch>.json` in the fixed schema. Validate it with `scripts/validate_critique.py`, then rewrite every entry with `score < 5` in Pass 2.
6. **Automated gate before finishing a locale.** Run `scripts/lqa_linter.py --fail-on-error` and `scripts/ui_expansion_checker.py --fail-on-high` (plus `scripts/font_glyph_scanner.py` for custom fonts) from `skills/game-cultural-localization/`. Exit `0` is required. Exit `1` means fix the findings. Exit `2` means the command or input is wrong (unknown locale, malformed file, missing column) and must be corrected, never ignored.
7. **Engine tokens are sacred.** Preserve every placeholder (`{0}`, `{name}`, `%s`, ICU plurals, Unreal `{Name}`), rich-text / BBCode tag, and mandatory leading/trailing space exactly. Keep proper names (the game's title, characters, factions, brands) as the context map records them. Never assume player gender.
